## 📌 项目简介

我是一名大二软件工程专业的学生，家里经营育苗场。每天需要通过飞书记录大量零散的报账消息，手动录入每条需要2-3分钟，还容易出错。

这个工具用 **TRAE SOLO + DeepSeek API** 搭建，能将自然语言消息一键解析为结构化的记账/订单模板，**全程只需10秒**。

### 核心功能

| 功能 | 说明 |
|------|------|
| 🤖 AI智能解析 | 自然语言 → 结构化数据，准确率95%+ |
| 📊 记账模式 | 自动识别收入/支出，支持日期、客户、电话、未结标记等 |
| 📋 订单模式 | 提取客户、品种、数量、地点、联系方式、出苗时间、定金 |
| 📅 日期批量设置 | 一键统一所有日期，解决家人经常忘写日期的问题 |
| 💾 历史记忆 | 自动保存解析结果，误关页面也能恢复 |
| 📋 一键复制 | 收入/支出分离复制，直接粘贴到飞书 |

### 效果对比

| 方式 | 单条耗时 | 10条耗时 | 准确率 |
|------|----------|----------|--------|
| 手动打字录入 | 2-3分钟 | 20-30分钟 | 依赖细心 |
| 飞书自带粘贴 | 30秒 | 5分钟 | ~60% |
| **本工具** | **10秒** | **30秒** | **95%+** |

> 已稳定使用1个月，处理记账记录200+条
